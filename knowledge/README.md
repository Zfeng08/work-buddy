# 知识库

这里是你的个人知识库，所有 `knowledge/**/*.md` 文件都会被自动分析。

## 写作规范

```markdown
---
title: 笔记标题
tags: [标签1, 标签2]
date: 2026-08-31
source: https://来源链接（可选）
---

正文。可以用 [[另一篇笔记标题]] 建立双向链接。
```

## 分析能力

每次定时任务运行 `scripts/build_knowledge.py` 后会生成 `data/knowledge.json`：

- **标签索引**：按标签聚合所有笔记
- **双向链接**：`[[标题]]` 手动建立强关联
- **内容相似度**：中文 bigram Jaccard 相似度自动发现潜在关联
- **知识图谱**：页面「图谱」标签页可视化所有关联，边的粗细代表关联强度

## 关联打分规则

| 关联来源 | 分数 |
|---|---|
| 显式双向链接 | +3 |
| 每个共同标签 | +2 |
| 内容相似度 × 5 | 0 ~ 5 |

总分 ≥ 2 才会被视为相关笔记。
