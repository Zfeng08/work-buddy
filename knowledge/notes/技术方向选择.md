# 技术方向选择

远程友好 + 学历门槛低 + 作品集可量化的方向排序：

## 候选方向

1. **前端开发**：作品集直观，远程岗位多，入门曲线平缓
2. **数据分析师**：教师的数据处理经验可迁移（成绩分析、教学统计）
3. **Python 自动化/爬虫**：这个工作台本身就是练手项目
4. **技术写作**：教学表达能力的直接变现，竞争小但天花板低

## 评估维度

- 远程岗位供给量（从工作台「岗位」页持续观察）
- 作品集构建周期
- 与现有能力的重叠度
